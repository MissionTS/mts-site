# Mission Technology Solutions Website

A Next.js + TypeScript + Tailwind CSS website for Mission Technology Solutions.

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Cloudways Velocity

Use the Next.js SSR preset, Node 22, root directory `./`, and the `main` branch after the initial site branch is reviewed and merged.
